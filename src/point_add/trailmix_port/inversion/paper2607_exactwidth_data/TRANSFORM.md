# Fixed-point bounded controlled-X reduction

These shards materialize exact cancellations of equal involutory X, CX, or CCX primitives separated only by mutually commuting X/CX/CCX primitives. Non-XOR primitives and shard boundaries are conservative barriers. The same exact rewrite is iterated until an authenticated zero-removal pass. The transformation preserves survivor order and is scoped to the open public ECDSA Fail reversible point-addition benchmark. It does not assert universal circuit correctness.
