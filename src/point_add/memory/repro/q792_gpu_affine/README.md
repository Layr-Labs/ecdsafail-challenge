# Offline exact affine predicate search on two Arc Pro B50
The ordinary submitted circuit uses only baked, independently verified NCT plans. OpenCL is an offline development dependency, not needed to build/run the circuit.
Build affine_search_r02.cpp using g++ -O3 -march=native -fopenmp -std=c++20, OpenCL headers and libOpenCL; use an Intel GPU OpenCL runtime exposing two distinct B50 devices.
Run executable bench <prefix> to compare fixed training/held-out truth functions and select a layout/workgroup; search <prefix> actual-jobs-r01.txt tune-r01-config.txt evaluates the actual predicate family and emits best.tsv/perf.tsv. It asserts all 18,219,008 GPU scores equal the 12-thread CPU reference and independently checks selected functions on all inputs.
The fixed 65,536-candidate bank per width contains invertible CX coordinate frames and X polarity. Candidate seed defines structural circuits only; canonical test seeds/nonces are never selected or changed.
GPU outputs rank by dirty-ladder Toffoli cost then operation cost. Integration additionally compares actual emitted NCT against the existing implementation, accepting only fewer Toffolis with nonincreasing operations and no additional qubits. The full final canonical9024 and native/lifecycle tests are independent qualification steps.
actual-r01-perf.tsv times include kernel execution and reading all output scores, excluding initialization/program compilation/input uploads. CPU reference uses 12 threads; one CPU timing and five measured GPU repetitions after warmup. Both cards have their own contexts and receive disjoint candidate ranges. Measurements are this workload only, not a whole-circuit speedup claim.
