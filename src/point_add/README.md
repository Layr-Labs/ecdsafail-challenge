# Q646 five-helper point addition with rotated dirty ladders

This circuit performs secp256k1 affine point addition on the competition's four input registers. It starts from the public five-helper circuit of odinfree and almond-lab's first cancellation and merge tables. The baseline for the four new compiler passes is the local Q646 circuit with compact SHA-256 `711db78b7ac4e37af8f1616440a173f365ef6036f80e9a4abed0bc4997e9fd01`. Its complete 9,024-input local replay measured 904,599,274 mean Toffolis. [Original public construction](https://api.ecdsa.fail/api/submissions/68f82159-a525-489e-8ff6-81f8d865346f)

The postpasses first decode exact dirty-ancilla ladders implementing multi-controlled XOR. They track symbolic zero wires through the actual register declarations, quantum gates and classical conditions. Where a zero wire is available, a prefix product can be computed and uncomputed there with two Toffolis. Each replacement restores all borrowed wires. A second pass chooses a cyclic orientation of each recognized distinct-control ladder. Its elementary gates commute with the complete multi-controlled toggle, so a rotation preserves the basis permutation on arbitrary, potentially entangled inputs. Rotations place identical involutions together and cancel them. Another pass shares controls between suitable pairs of toggles. Finally, the source peephole optimizer runs three rounds on 262,144-operation windows. All other passes use continuous 8,192-operation windows. Measurements and the boundaries of conditional regions stay in program order.

The normal Rust entry point expands the published schedule, checks the parent length, streams it through these four passes and returns the stock operations. The original sign, five helpers and two quantum coordinate registers use 646 wires in total. The shipped implementation introduces no measurements. The competition benchmark counts executed Toffolis separately for each input derived from the compiled gate stream.
